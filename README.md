# Bandcamp Volume Slider Chrome Extension
This is a browser extension for Chrome that adds a volume slider to an album's Bandcamp page and also moves the tracklist so it's displayed near the playback controls instead of at the bottom of the page.

To install:
- Download or clone this repo
- Open `chrome://extensions`
- Turn on Developer mode at the top right of the the extensions page
- Click "Load unpacked" and select the `bc-volume-extension` folder
